ВЫЛЕТЫ СОТРУДНИКОВ — установка

1. Залейте все файлы из архива на GitHub в новый репозиторий (или в отдельную папку
   существующего), включите GitHub Pages: Settings → Pages → Deploy from branch → main.
   Подойдёт и Netlify Drop: перетащить папку на https://app.netlify.com/drop
2. Откройте полученную ссылку (https://…) на телефоне и на ПК.
3. Установите:
   • Android, Chrome: меню ⋮ → «Добавить на главный экран» / «Установить приложение».
   • iPhone, Safari: «Поделиться» → «На экран Домой».
   • ПК, Chrome или Edge: значок установки справа в адресной строке.
4. Дальше работает без интернета. Данные хранятся на каждом устройстве отдельно.

ОБМЕН ТЕЛЕФОН ⇄ ПК
• «Отправить файл» на устройстве, где меняли данные → отправить себе в Telegram «Избранное».
• На другом устройстве «Принять файл» → выбрать файл (на ПК можно перетащить в окно).
• Меняли на обоих — отправьте в обе стороны. Данные объединяются, а не затираются.
• Поставьте одинаковый пароль на файл обмена на обоих устройствах: в файле паспорта.

ФОТО ДОКУМЕНТОВ
• Фото и PDF хранятся на устройстве. При обмене каждое новое фото уходит один раз,
  чтобы файлы обмена оставались маленькими.
• Новый телефон или ПК: «Обмен» → «Полная копия с фото» — все данные и все фото сразу.

ОФОРМЛЕНИЕ ЗАЯВОК (раздел «Оформить»)
• Шаг 1: выбрать людей и рейсы. Рабочие идут в одну общую заявку Excel,
  ИТР, офис и руководство — каждый в свою заявку Word.
• Шаг 2: проверка данных. Красным — чего не хватает или что неверно, исправляется прямо там.
• Шаг 3: номер и дата заявки → «Скачать Excel» / «Скачать Word».
• Бланки лежат в папке shablon. Если поменяются подписанты или форма — исправьте бланк
  и загрузите: «Обмен» → «Бланки заявок» → «Заменить».

ЗАГРУЗКА СВОИХ ФАЙЛОВ
• «Обмен» → «Загрузить свои Excel / Word». Можно выбрать сразу несколько файлов: таблицы Excel,
  CSV, таблицы в Word, заявки на билеты Word. Старые .xls/.doc сначала пересохраните как .xlsx/.docx.
• Программа угадывает, что в каком столбце, и показывает это. Поправьте, если нужно, и нажмите
  «Загрузить». Для того же файла в следующий раз столбцы запомнятся.

УХОД СОТРУДНИКА
• В карточке: «Не продлевают контракт или увольнение…» → дата, вылет домой с причиной
  «Увольнение», лишние рейсы после ухода удаляются. После даты человек уходит в фильтр «Уволены».

ОБНОВЛЕНИЕ
Заменяете файлы на GitHub — приложение само предложит «Обновить». Данные не теряются.
